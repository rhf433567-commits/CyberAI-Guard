# CyberAI Guard 🛡️🤖

An intelligent cybersecurity system designed to detect phishing messages using Machine Learning and Python. The application evaluates incoming text and embedded URLs, assigning a risk level, confidence score, and detailed security breakdown through a modern Graphical User Interface (GUI).

---

## 🌟 Key Features

* **Phishing Detection:** Classifies messages (Phishing vs. Legitimate) using a trained Machine Learning model.
* **Risk Assessment & Confidence Score:** Categorizes risk levels (Very High, High, Medium, Low) and calculates confidence percentages.
* **URL Analysis:** Analyzes embedded links within messages for suspicious patterns.
* **Modern GUI:** Interactive desktop application built with `CustomTkinter`.
* **Export & Report History:** Tracks and logs previous evaluations.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **GUI Framework:** CustomTkinter
* **Machine Learning:** Scikit-learn, Joblib, Pickle
* **Data Processing:** Pandas, NumPy
